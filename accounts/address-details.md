# Address Details

The address page links to transactions, token transfers, internal transactions, balances and available contract tabs. Compare the complete address, not just its first and last characters, before sending funds.

TURK balance is native value; token holdings are balances in separate contracts. A displayed name, public tag or token icon is metadata. It does not alter the address or prove its controller.

Use `GET /api/v2/addresses/{address_hash_param}` for indexed address data and `eth_getBalance` on the RPC for node state. [Address API](../api-documentation/addresses-api.md) includes exact parameters and examples.

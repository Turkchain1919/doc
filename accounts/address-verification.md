# Address Verification

Address ownership verification uses a challenge signed by the controlling wallet. Read the exact message, domain, address and purpose before signing. A legitimate ownership challenge should not require broadcasting a payment.

A successful proof can support explorer account features and metadata requests. It is separate from deploying code, verifying Solidity source, or receiving an administrator's Certified label.

The audit did not sign an ownership challenge or modify user accounts. See [Security Warnings](../faq/security-warnings.md).

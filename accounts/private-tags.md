# Private Tags

Private address and transaction tags belong to the signed-in explorer account. They help organize activity without publishing the label as a public address tag.

Open the account's tag section when available, choose the full address or transaction hash, and save the label. Verify the selected network and account before relying on it. Private labels do not change contract state and do not prove address ownership.

Do not store seed phrases, keys or other secrets in tags. Sign-in and persistence must be tested with a real user session; the audit confirmed account support is enabled but did not create or modify private user data.

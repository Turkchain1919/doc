# Token Holdings

Token holdings are indexed balances associated with an address. ERC-20 balances have token-specific decimals; ERC-721 and ERC-1155 represent token IDs and ownership or quantities.

A spam token can appear without permission. Do not interact with it to remove it from an explorer view. Importing a token into a wallet changes the wallet display, not on-chain ownership.

Use the address token-balance and NFT endpoints in the [API reference](../api-documentation/addresses-api.md). Missing USD values reflect missing prices; do not compute portfolio value from an unverified token quote.

# TurkScan® API V2 Overview

Send HTTPS GET requests to the documented resource paths. JSON field names, path parameters and action identifiers are part of the API contract and retain their technical spellings.

The live specification listed 114 paths during the audit, including generic or optional features. The [availability matrix](availability.md) records which operations were tested and their actual result. The category references below include parameter requirements, exact tested URLs, requests, captured responses and error behavior.

Native amounts are in 18-decimal base units unless the field states otherwise. Token decimals vary. Keep decimal strings precise; do not convert balances to floating point. Null prices mean unavailable data.

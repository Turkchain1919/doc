# Bridge Security

Cross-chain transfers add security assumptions beyond either chain: router ownership, validators or security modules, relayers, hooks, upgrade controls and asset backing. Inspect each route's actual configuration.

Use bounded allowances, confirm destination domains and addresses, and test a small transfer only after the route has been verified. Never disclose recovery phrases to recover a delayed transfer.

A registry listing, token icon or source-verified contract is not proof that a route is solvent, correctly configured or operational. No safety guarantee or completed transfer is asserted by the current audit.

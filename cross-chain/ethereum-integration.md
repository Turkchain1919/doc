# Ethereum Integration

EVM compatibility lets developers use familiar Ethereum tooling on Turkchain®; it does not automatically create an Ethereum bridge or make the two chains' balances interchangeable.

An Ethereum-to-Turkchain transfer needs a verified route for the exact asset, correct destination domain and active delivery infrastructure. Keep source and destination transaction hashes. Network `1919` is Turkchain, while Ethereum mainnet has its own chain ID and fee currency.

This audit did not execute an Ethereum cross-chain transfer. See [Warp Routes](warp-routes.md) before treating an asset route as supported.

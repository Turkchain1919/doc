# Solana Integration Roadmap

Solana support is a roadmap topic. This audit did not establish a live Turkchain–Solana route, deployed route contracts, supported assets or completed delivery.

A future launch needs independently verified program and EVM contract addresses, asset mappings, decimal conversions, recipient encoding, security configuration, relaying and recovery procedures. Publish test evidence and deployment references before marking it live.

Do not send funds using inferred addresses or assume that EVM tooling handles Solana transaction formats.

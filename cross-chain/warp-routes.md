# Warp Routes and Supported Assets

A Warp Route connects specific asset contracts across specific domains. Confirm the route's exact source and destination token addresses, decimals, router enrollment, security module, hooks and backing model.

No canonical Turkchain Warp Route or supported-asset matrix was established by this audit. Do not deposit to a router inferred from a ticker, search result or generic mailbox address. The mailbox is infrastructure, not a universal asset deposit address.

Publish a route as live only after validating deployed code, configuration and end-to-end delivery. Wrapped or bridged assets require their own backing and redemption documentation.

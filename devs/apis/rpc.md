# TurkScan® Explorer API Compatibility

TurkScan® exposes a module/action API at `https://turkscan.com/api`. Some account, transaction, contract, block, token, log and statistics actions were verified by read-only requests.

It is not the Etherscan-hosted multichain API V2 and does not use an Etherscan service key. Module and action names are protocol identifiers and remain unchanged.

See the [compatibility reference](../../api-documentation/compatibility-api.md), [compatibility matrix](../../api-documentation/compatibility-matrix.md) and [error handling](../../api-documentation/error-handling.md).

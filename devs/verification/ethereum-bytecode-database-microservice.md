# Verified Source and Bytecode Matching

TurkScan® uses source-verification tooling to compare compiler output with deployed bytecode. A matching result can expose source and ABI on a contract page.

A match discovered through a bytecode database is different from an administrator certification or a fresh user submission. Review the exact match status, constructor settings and implementation address. Partial or similar-bytecode matches must not be presented as a full security audit.

The deployment's verification configuration reports the Rust verifier enabled. This page does not promise external database availability or publish private service addresses. See [Verified Source](../../smart-contracts/contract-verification.md).

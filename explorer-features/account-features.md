# Account Features

The deployment has explorer account support enabled. Account UI includes API keys, private tags, watchlists and address-ownership workflows where configured. These use an explorer account and may also require wallet signatures.

The public API audit did not log in, create keys, save private tags or sign ownership messages. Private/account endpoints are not presented as unauthenticated public APIs.

See [Private Tags](../accounts/private-tags.md), [Address Verification](../accounts/address-verification.md) and [API Authentication](../api-documentation/authentication-and-api-keys.md).

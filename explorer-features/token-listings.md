# Token Listings and Verified Contracts

The token directory indexes recognized token contracts and exposes their standard, holder count and available metadata. A listing does not establish official status or safety.

The verified-contract directory lists contracts with indexed source verification information. Open a contract to inspect source, ABI, compiler settings and proxy implementation. Administrator certification is an additional metadata signal.

Use [Token Information](../using-blockscout/overviews/token-info.md) and [Certified Contracts](../smart-contracts/certified-contracts.md) to distinguish these signals.

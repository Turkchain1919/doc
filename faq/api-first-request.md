# Your First TurkScan® API Request

The explorer API reads indexed data, while the network RPC reads node state. Public read examples in the audit succeeded without an API key.

## What to check

Request https://turkscan.com/api/v2/config/backend-version and inspect HTTP status and JSON. Use the API reference for resource paths rather than calling the bare /api/v2 directory. Never paste production credentials into a support message.

## Further guidance

[Read the detailed TurkScan guide](../api-documentation/request-examples.md). If the issue persists, retain the public identifiers and exact error while keeping secrets out of the report.

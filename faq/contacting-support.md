# Preparing a Support Request

A useful issue report identifies the network, public transaction or contract, time, relevant page and exact error. It separates what was expected from what the receipt or API returned.

## What to check

Include chain ID 1919 and full public hashes. Redact session cookies, API keys, recovery phrases, passwords and personal information. Use support links from the current TurkScan site rather than unsolicited direct messages.

## Further guidance

[Read the detailed TurkScan guide](../faq/security-warnings.md). If the issue persists, retain the public identifiers and exact error while keeping secrets out of the report.

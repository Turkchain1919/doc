# Reading the Contract Code Tab

The contract page can expose source, ABI, compiler settings, constructor data and implementation links where indexed and verified. A Certified operator label is separate from the source match.

## What to check

Confirm the exact contract address, inspect the match type and follow proxy implementation links. Review access controls and upgrades. A source match makes inspection possible but is not a guarantee of safety.

[Read the detailed TurkScan guide](../smart-contracts/contract-verification.md). If the issue persists, retain the public identifiers and exact error while keeping secrets out of the report.

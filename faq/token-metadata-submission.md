# Token Metadata Submission

A metadata request should identify the exact Turkchain contract and provide accurate name, symbol, project references and icon. Source verification and administrator metadata approval are separate decisions.

## What to check

Use the current TurkScan review workflow. Provide reproducible public evidence and do not claim a badge before approval. No paid expedited-review address was verified in this audit.

## Further guidance

[Read the detailed TurkScan guide](../using-blockscout/token-info.md). If the issue persists, retain the public identifiers and exact error while keeping secrets out of the report.

# Contract Interaction

Find the full contract address on TurkScan® and inspect its verified source, ABI and proxy implementation where available. Read methods query state without persisting it. Write methods require a signed transaction and TURK for gas.

Check the selected network, method, arguments, payable value and spender before signing. Simulate when possible. A successful simulation can become invalid if state changes before inclusion.

See [Read & Write Contract](../smart-contracts/read-and-write-contract.md), [ABI & Encoding](../smart-contracts/abi-and-encoding.md) and [Security](../smart-contracts/security-best-practices.md).

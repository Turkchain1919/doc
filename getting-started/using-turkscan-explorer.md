# Using TurkScan® Explorer

1. Open `https://turkscan.com` and paste an address, complete transaction hash or block number into Search.
2. Open the matching result and confirm its full identifier.
3. For transactions, inspect status, block, timestamp, sender, recipient, value and fee. Token transfers and internal calls are separate views of execution.
4. For tokens, confirm the contract address and standard. Review holders and transfers where indexed.
5. For contracts, check whether source code is verified before using Read or Write Contract.

A green badge, familiar logo or matching ticker is not a guarantee of security. A missing fiat price means unavailable pricing data, not zero asset value. Never send funds to a contract unless the intended operation is supported.

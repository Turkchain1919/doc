# Wallet Configuration

Use the values in [Network Information](../introduction/network-information.md). Keep wallet software updated and confirm the chain ID in signing prompts.

A hardware wallet may require enabling EVM application support. Check its vendor's supported transaction formats. Do not import a hardware-wallet seed into a website to solve a connection issue.

Token visibility is configured separately from network connectivity. Import an ERC-20 by its verified contract address; do not add a contract address for native TURK. Disconnecting a website does not revoke existing token approvals.

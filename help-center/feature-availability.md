# TurkScan® Feature Availability

EVM execution makes standard wallet and contract operations possible, while explorer tools such as AI explanations, premium plans, bulk metadata exports and custom analytics are separately deployed services.

## What to check

Use the documented TurkScan resource or RPC counterpart. Check the API availability inventory for observed results. This guide does not invent a premium subscription, AI endpoint, relayer service or chain-specific consensus feature.

## Further guidance

[Read the detailed TurkScan guide](https://doc.turkscan.com/api-documentation/availability). If the issue persists, retain the public identifiers and exact error while keeping secrets out of the report.

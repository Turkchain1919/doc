# Message Signatures and Transactions

A message signature can be used for an ownership challenge or another application authorization. A transaction changes chain state after broadcast and successful execution. Typed-data signatures can also authorize valuable actions.

## What to check

Read the exact domain, message, spender and purpose. Do not assume a signature is harmless because it does not immediately charge gas. Use the TurkScan ownership workflow only for a challenge you initiated.

## Further guidance

[Read the detailed TurkScan guide](https://doc.turkscan.com/accounts/address-verification). If the issue persists, retain the public identifiers and exact error while keeping secrets out of the report.

# Token Icons and Branding

An icon is display metadata and does not establish asset ownership or canonical status. TurkScan administrator controls manage supported branding and icon fields independently of blockchain balances.

## What to check

Submit the correct contract, a clear project-owned image and accurate references. Check the published image URL loads over HTTPS and retains the expected appearance on light and dark backgrounds. Do not change an API or token contract address to update an image.

## Further guidance

[Read the detailed TurkScan guide](https://doc.turkscan.com/tokens/official-tokens). If the issue persists, retain the public identifiers and exact error while keeping secrets out of the report.

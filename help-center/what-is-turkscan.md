# What is TurkScan®?

TurkScan® is a public explorer for Turkchain® Mainnet. It indexes blockchain data so you can inspect addresses, transactions, blocks, token events and verified contract source. It does not hold your wallet keys or execute refunds.

## What to check

Start with a full transaction hash or address, confirm the network and read the result status. Public browsing does not require connecting a wallet.

## Further guidance

[Read the detailed TurkScan guide](https://doc.turkscan.com/getting-started/using-turkscan-explorer). If the issue persists, retain the public identifiers and exact error while keeping secrets out of the report.

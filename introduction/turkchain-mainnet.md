# Turkchain® Mainnet

Use mainnet with real TURK and real contract state. Check chain ID `1919` before signing, review the recipient and amount, and retain the transaction hash.

The [network configuration](network-information.md) is shared by wallets and development clients. There is no testnet faucet or testnet endpoint verified by this documentation. Test contracts locally before deploying to mainnet; local success does not guarantee mainnet execution.

The explorer's indexed height and the node's `eth_blockNumber` can temporarily differ. Diagnose this through the transaction receipt and indexing status instead of submitting a duplicate payment.

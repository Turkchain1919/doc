# Certified Contracts and Verified Source

TurkScan® Certified is an administrator-managed review label. It is separate from verified source code and from on-chain access-control ownership.

Source verification requires a bytecode match. An administrator's MFA-approved certification must not create a fabricated source match when no verified-source record exists. Review the actual Code tab, ABI availability and implementation before interacting.

Certification can change as metadata. It does not guarantee safety, eliminate upgrade privileges or insure deposits. See [Contract Ownership](contract-ownership.md).

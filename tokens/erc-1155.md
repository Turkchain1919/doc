# ERC-1155 Tokens

ERC-1155 supports multiple token IDs and quantities within one contract. A token ID can represent fungible or limited-edition units. Transfers may be single or batched.

Balance interpretation requires the contract address, token ID and owner. Do not reuse ERC-20 decimal assumptions. TurkScan® indexes supported transfer events and NFT-instance views where the contract follows recognized interfaces.

Check the parent transaction for batch operations; counting event rows as distinct user transactions can overstate activity. See [NFT API](../api-documentation/nft-api.md).

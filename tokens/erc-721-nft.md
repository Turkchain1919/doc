# ERC-721 NFTs

ERC-721 represents unique token IDs within a contract. The asset identity is the chain, contract address and token ID together. Ownership is queried through the contract; an image alone does not prove ownership.

TurkScan® can index NFT collections and instances. Metadata and media can be external, mutable, unavailable or misleading. Do not execute downloaded files or connect a wallet to claim an unsolicited NFT.

See [NFT API](../api-documentation/nft-api.md). A route returning an empty list means no indexed items for that query, not that a collection is endorsed.

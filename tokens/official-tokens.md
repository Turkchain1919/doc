# Official Tokens and Icons

A token is not official merely because its name, ticker or logo resembles Turkchain®. Verify its exact contract address against independently maintained project references and explorer source information.

Token icons are display metadata. They can be missing or updated without a token transfer. Submit updates through the supported TurkScan® review workflow; do not treat an icon upload as proof that the contract is safe.

This documentation does not publish an unverified official-token allowlist. Native TURK has no ERC-20 contract address. See [Wrapped TURK](wrapped-turk.md) for the separate wrapped-asset checks.

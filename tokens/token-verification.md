# Token Verification and Badges

Token verification is an operator-managed metadata decision, while source verification checks submitted contract source against deployed bytecode. These are separate signals.

The current TurkScan® administrator workflow supports Verified token metadata and Certified contract decisions with administrator authentication and MFA. A label does not constitute a code audit, guarantee, endorsement of returns or proof of ownership.

Use the token's exact contract address when requesting metadata updates. Provide accurate project information and a repository-hosted icon where possible. The public documentation does not offer a bypass of administrator review.

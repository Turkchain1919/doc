# Copy and Sign an Ownership Message

Start the challenge from the authenticated TurkScan® address-ownership workflow. Confirm the domain, address, purpose and message text in the wallet before signing.

A message signature can prove control of the signing address for that challenge. It should not require a native transfer, token allowance or disclosure of a recovery phrase. Do not sign unexplained typed data or transaction requests under the label of ownership verification.

The audit did not sign a challenge. See [Address Verification](../../../accounts/address-verification.md) and [Security Warnings](../../../faq/security-warnings.md).

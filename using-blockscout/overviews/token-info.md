# TurkScan® Token Information

The token information panel shows the indexed contract address, standard, name, symbol, decimals, supply and available metadata. The historic URL path is retained so existing explorer links continue to work.

Confirm the full contract address before relying on a token name or icon. Total supply is not circulating supply. Missing price and market-cap fields are unavailable values, not zero. Holder and transfer counts reflect indexed data and can lag the node.

Verified token metadata is an operator review decision; verified source is a bytecode/source match. Neither is a complete security audit.

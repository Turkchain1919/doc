# TurkScan® Token Metadata Review

Token metadata updates must identify the exact Turkchain® contract and provide accurate name, symbol, icon and project references. Use the current TurkScan review workflow from the explorer.

No paid expedited-review service or payment address was verified in this audit. Do not send funds based on a generic upstream review link. Administrator-approved metadata and source-code verification are separate.
